# Node.js (NestJS) Skills

## Purpose
Highly condensed, deterministic building blocks for NestJS architecture. 

## Directory Index
| Skill | Trigger | Core Topic |
| --- | --- | --- |
| `modules-di` | Feature scoping | `@Module`, Dependency Injection, Encapsulation |
| `controllers-routing` | HTTP Endpoints | `@Controller`, Extracting payloads, `@Body` |
| `providers-services` | Business Logic | `@Injectable`, Custom providers, Throwing Exceptions |
| `pipes-validation` | Payload Validation | `ValidationPipe`, `class-validator`, DTO classes |
| `guards-auth` | Route Protection | JWT, Roles, `@UseGuards`, Metadata extraction |
| `interceptors-filters` | Global Formats | Global error catching, RxJS mapping, `@Exclude` |
| `database-integration` | DB Access | TypeORM / Prisma, Repositories, Transactions |

# React Native Skills

## Purpose
Condensed, deterministic rules for building modern Expo/React Native apps.

## Directory Index
| Skill | Trigger | Core Topic |
| --- | --- | --- |
| `component-composition` | UI Construction | Pure components, `children` prop, separating Data from UI |
| `state-management` | API & Local State | React Query (Server), Zustand (Client), avoiding `useEffect` |
| `navigation-routing` | File-based Routes | Expo Router (`app/`), passing primitive IDs, Layouts |
| `styling-layout` | UI Styling | NativeWind, Flexbox exclusively, `SafeAreaView` |
| `performance-optimization`| Heavy UIs | `FlashList`, `React.memo`, extracting inline functions |
| `platform-integration` | Native Device APIs | Expo Config Plugins, `Platform.OS`, iOS vs Android styling |

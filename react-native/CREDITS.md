# React Native Technology Pack Credits

This technology pack was generated to integrate seamlessly with the OpenCode Engineering Framework.

## Based On
The guidelines, rules, and workflows in this pack are derived from:
- Official [React Documentation (react.dev)](https://react.dev/)
- Official [React Native Documentation](https://reactnative.dev/)
- Official [Expo Documentation](https://docs.expo.dev/)
- Modern production standards from the React Native community (2024+)

## Key Architectures Referenced
- **State Management:** Zustand for global state, React Query (TanStack) for server state.
- **Routing:** Expo Router (file-based routing).
- **Styling:** NativeWind (TailwindCSS) and standard StyleSheet.
- **Performance:** `@shopify/flash-list`, `expo-image`, and `react-native-reanimated`.
- **Testing:** Jest and `@testing-library/react-native`.

## Purpose
Designed by the OpenCode AI Agent system to provide a unified, enforceable, and modern knowledge base for building scalable React Native (Expo) applications, avoiding outdated patterns (like class components, Redux boilerplate, or bare React Navigation without layouts).
